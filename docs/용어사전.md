# PrePair 용어 사전 (Member · OAuth)

> 본 사전은 PrePair 중 **회원 관리(Member)** 와 **OAuth** Bounded Context에 한정한 유비쿼터스 언어(Ubiquitous Language)다.
> 면접(Interview/Answer/Feedback) 관련 용어는 본 리팩토링 범위 밖이므로 포함하지 않는다.
> 새로운 도메인 개념을 도입하거나 명칭을 변경할 때는 이 표를 먼저 갱신한다.

## 회원

| **한국어** | **영어** | **설명** |
|---|---|---|
| 회원 | Member | PrePair 서비스를 이용하는 사용자. 이메일/비밀번호 또는 카카오 OAuth로 가입한다. Aggregate Root. |
| 이메일 | Email | 회원 식별 수단이자 알림 수신 주소. 정규식으로 형식 검증을 거치는 Value Object. |
| 비밀번호 | Password | 회원 인증 자격증명. 8자 이상 정책이 적용되며 해시 형태로만 저장되는 Value Object. |
| 직업 | Job | 회원이 등록한 직군. 외부 컨텍스트(면접)가 컨텍스트로 사용한다. |
| 닉네임 | Nickname | 회원의 표시 이름. |
| 프로 회원 | Pro Member | 유료 구독을 통해 추가 기능을 이용하는 회원(`Member.isPro`). 현재는 플래그만 존재. |
| 포인트 | Point | 회원에게 적립되는 보상 단위(`Member.point`). 외부 컨텍스트(리워드)가 답변 점수를 기반으로 적립을 호출한다. |
| 인증 코드 | VerificationCode | 이메일 본인 확인용 4자리 숫자. 발급 후 5분간 유효. |
| 등록 토큰 | VerificationToken | 이메일 인증 통과 후 발급되는 UUID 기반 토큰. 비밀번호 재설정·이메일 변경·OAuth 신규 가입의 사전 자격. 5분간 유효. |
| 비밀번호 인코더 | PasswordEncoder | 평문 비밀번호를 해시하고 비교하는 도메인 서비스 인터페이스. 구현은 인프라가 제공. |
| 알림 채널 | NotificationChannel | 회원이 선택한 알림 수신 채널(`EMAIL`/`KAKAO`/`BOTH`). 회원의 선호도 필드이며 발송 자체는 다른 컨텍스트의 책임. |
| 알림 빈도 | NotificationFrequency | 회원이 선택한 알림 빈도(`EVERY`=매일 / `WEEKLY`=주간). 회원의 선호도 필드. |

## OAuth

| **한국어** | **영어** | **설명** |
|---|---|---|
| OAuth 연결 | OAuthConnection | 회원과 외부 OAuth 제공자 간 1:1 연결을 표현하는 Aggregate Root. |
| OAuth 제공자 | OAuthProvider | 외부 인증 제공자(`kakao`/`google`/`naver`). 현재는 카카오만 어댑터 구현. |
| 제공자 사용자 ID | ProviderId | OAuth 제공자가 발급한 사용자 식별자. 회원 ID와는 별개. |
| 카카오 콜백 | Kakao Callback | 카카오 OAuth 인가 코드 교환 단계. 기존 로그인/자동 연결/신규 등록 토큰 발급 세 가지로 분기. |
| 자동 연결 | Auto Link | 카카오 이메일이 기존 회원의 이메일과 일치할 때 자동으로 `OAuthConnection`을 생성하는 시나리오. |
| 신규 등록 토큰 | Registration Token | 카카오 콜백에서 기존 회원이 없을 때 5분 유효로 발급되는 가입 사전 자격(`VerificationToken`을 활용). |
| 계정 연결 | Account Linking | 기존 이메일 회원이 자신의 계정에 카카오 OAuth를 사후 연결하는 행위. |

## 인증·인가

| **한국어** | **영어** | **설명** |
|---|---|---|
| 액세스 토큰 | Access Token | JWT 기반 단기 인증 토큰. API 호출 시 `Authorization` 헤더에 포함. |
| 리프레시 토큰 | Refresh Token | 액세스 토큰 재발급용 장기 토큰. 별도 저장소에 보관. |
| JWT | JSON Web Token | 인증·인가에 사용되는 토큰 표준. |
| 가드 | Guard | NestJS 인증 가드(`JwtAuthGuard`). |
| 이메일 인증 | Email Verification | 회원 가입·비밀번호 재설정·이메일 변경에 공통으로 사용되는 본인 확인 흐름(인증 코드 → 등록 토큰). |

## 아키텍처·DDD 패턴

| **한국어** | **영어** | **설명** |
|---|---|---|
| 어그리거트 루트 | Aggregate Root | 트랜잭션 일관성 경계의 진입점이 되는 도메인 객체. |
| 값 객체 | Value Object | 식별성이 없고 속성으로 동등성이 판단되는 불변 도메인 객체. |
| 도메인 서비스 | Domain Service | 단일 Aggregate에 속하지 않는 도메인 로직을 담는 무상태 서비스. |
| 도메인 이벤트 | Domain Event | 도메인 상태 변화를 표현하는 불변 사실(fact). |
| 도메인 예외 | Domain Exception | 비즈니스 규칙 위반을 나타내는 예외 베이스 클래스. |
| 리포지토리 | Repository | Aggregate 영속화를 추상화한 포트. 도메인 레이어에 인터페이스만 둔다. |
| 이벤트 저장소 | EventStore | 도메인 이벤트를 append-only로 저장·재생하는 포트. |
| CQRS | Command Query Responsibility Segregation | 명령(Write)과 조회(Read) 모델을 분리하는 패턴. 현재 Member 도메인에 적용. |
| 이벤트 소싱 | Event Sourcing | 상태를 직접 저장하지 않고 이벤트 스트림으로 표현해 재구성하는 패턴. Member에 적용. |
| 헥사고날 아키텍처 | Hexagonal Architecture | 도메인을 중심에 두고 외부 의존성을 포트와 어댑터로 격리하는 아키텍처. |
| 포트 | Port | 도메인이 외부에 요구하는 능력을 표현한 인터페이스. |
| 어댑터 | Adapter | 포트를 실제 기술(DB/HTTP/외부 API)로 구현한 컴포넌트. |
| 컨텍스트 경계 | Bounded Context | 동일한 용어가 동일한 의미로 통하는 도메인의 부분 집합. |
| 컨텍스트 맵 | Context Map | Bounded Context 간 상호작용 방식을 표현한 다이어그램/표. |
| 유비쿼터스 언어 | Ubiquitous Language | 도메인 참여자 모두가 공유하는 일관된 용어. |
