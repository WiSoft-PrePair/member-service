- [x] **VerificationToken** (`verification-token.ts`)

## 4. Auth Context (인증)

> **주의:** Auth는 별도의 Bounded Context가 아니며, CQRS를 사용하지 않습니다.

**구현 방식:**
- 전통적인 Service 패턴
- JWT 기반 토큰 인증 (Access Token + Refresh Token)
- Passport Strategy 사용

**주요 컴포넌트:**
> 파일: `src/adapter/auth/`

- [x] `AuthService`: 로그인/로그아웃 로직
- [x] `JwtAuthService`: JWT 토큰 생성/검증
- [x] `JwtStrategy`: Passport JWT 전략
- [x] `JwtAuthGuard`: 인증 가드
- [x] `RefreshTokenRepository`: Refresh Token 저장소

**참고 문서:**
- `docs/authentication-implementation-guide.md`: 인증 구현 가이드
